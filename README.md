# Инвентарь RPG-игры: Применение паттернов проектирования

## Описание проекта

Консольное приложение на C# (.NET 8), реализующее систему инвентаря для ролевой игры с использованием паттернов проектирования **Composite** и **Prototype**.

Система поддерживает:
- Вложенные контейнеры (сумки внутри сундуков)
- Рекурсивный подсчёт общего веса и стоимости
- Клонирование предметов по образцу без знания их конкретного класса

## Использованные паттерны

### 1. Composite (Компоновщик)
Позволяет единообразно обрабатывать одиночные предметы (меч, зелье) и контейнеры (сумка, сундук), включая рекурсивный подсчёт веса и стоимости.

### 2. Prototype (Прототип)
Позволяет создавать копии предметов по образцу без знания их конкретного класса.
